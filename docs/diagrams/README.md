# Architecture diagram sources

- `context.mmd`: system context, Mermaid source.
- `components.mmd`: draft component architecture, Mermaid source.
- `use-cases.puml`: UML use-case diagram, PlantUML source.

These are proposed design artifacts, not evidence of implemented components. Readable exports are to be included in the consolidated report. Android and web are production-intended clients, not device simulators.
